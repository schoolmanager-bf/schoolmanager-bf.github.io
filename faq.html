❓ Questions fréquentes

Tout ce que vous devez savoir sur SchoolManager BF

SchoolManager est-il vraiment gratuit ?
La version Démo est 100% gratuite et permet de gérer jusqu'à 150 élèves avec toutes les fonctionnalités de base. Le watermark "VERSION DEMO" apparaît sur les bulletins PDF. Pour le retirer et avoir des fonctionnalités avancées, passez au Pack École (250 000 FCFA à vie).
Comment fonctionne le QR code anti-fraude ?
Chaque bulletin généré contient un QR code signé numériquement (HMAC-SHA256). N'importe qui peut scanner ce QR avec son téléphone (iPhone, Android, WhatsApp) pour vérifier l'authenticité du document sur notre site officiel. Si quelqu'un modifie une seule note sur le PDF, la vérification échoue.
Puis-je utiliser le logiciel sur plusieurs PC ?
Oui ! Le Pack Réseau Pro (450 000 FCFA) permet jusqu'à 5 PC connectés en réseau local. La base de données est synchronisée automatiquement entre tous les postes.
Comment installer SchoolManager ?
Téléchargez l'installateur depuis notre site, double-cliquez sur le fichier .exe, suivez l'assistant d'installation, et c'est prêt ! L'installation prend moins de 2 minutes. Consultez le manuel pour plus de détails.
Mes données sont-elles sécurisées ?
Oui. La base de données est chiffrée avec SQLCipher (AES-256). Les mots de passe sont hashés avec PBKDF2 (300 000 itérations). Les sauvegardes sont automatiques. Vous pouvez aussi exporter vos données à tout moment.
Comment mettre à jour le logiciel ?
Téléchargez la dernière version depuis le site et réinstallez. Vos données sont conservées automatiquement. Nous vous informons des mises à jour via l'application.
Puis-je personnaliser les bulletins ?
Oui. Vous pouvez configurer le logo de l'école, le nom, l'adresse, les couleurs, et le système de notation (sur 10 ou sur 20). Les bulletins incluent automatiquement les notes, moyennes, rang, conduite et décision.
