Manuel d'utilisation

Guide complet de Yiriba v2.0

1. Installation

1Téléchargez l'installateur depuis schoolmanager-bf.github.io
2Lancez Yiriba_BF_Setup.exe et suivez l'assistant
3À la première ouverture, l'écran d'activation s'affiche. Collez votre clé de licence ou cliquez "Version Démo"

2. Connexion

Entrez votre identifiant et mot de passe. Par défaut :

  • Utilisateur : admin
  • Mot de passe : admin123
⚠️ Important : Changez le mot de passe dès la première connexion dans Paramètres.

3. Paramétrage initial

Allez dans Paramètres pour configurer :

  • Informations de l'école : Nom, adresse, téléphone, logo
  • Année scolaire : Créez l'année en cours (ex: 2025-2026)
  • Système de notation : Sur 10 ou sur 20, pondération D1/D2/Composition
  • Utilisateurs : Créez les comptes Secrétaire, Comptable, Directeur

4. Inscription des élèves

  1. Créez d'abord les classes (Menu → Classes)
  2. Puis les élèves (Menu → Élèves → Nouveau)
  3. Enfin, inscrivez l'élève dans sa classe (Menu → Inscriptions)
💡 Astuce : Vous pouvez importer une liste d'élèves depuis Excel (Menu → Import Excel).

5. Saisie des notes

  1. Menu → Notes
  2. Sélectionnez la classe et la période (Trimestre 1/2/3)
  3. Sélectionnez l'élève
  4. Remplissez les notes pour chaque matière : D1, D2, Composition
  5. La moyenne se calcule automatiquement
  6. Cliquez Enregistrer
💡 Notes décimales : Tapez directement 14,5 ou 12.75. Les deux formats sont acceptés.

6. Génération des bulletins

  1. Menu → Notes → sélectionnez l'élève
  2. Cliquez Générer le bulletin
  3. Le bulletin PDF est créé avec : photo, notes, moyenne, rang, conduite, décision
  4. Le bulletin contient un QR code vérifiable en ligne

7. Paiements

  1. Menu → Paiements
  2. Cliquez Nouveau paiement
  3. Sélectionnez l'élève, le montant, le mode de paiement
  4. Le reçu généré contient aussi un QR code anti-fraude

8. Vérification en ligne

Scannez le QR code d'un bulletin ou reçu avec n'importe quel scanner (caméra téléphone). Le navigateur ouvrira :

https://schoolmanager-bf.github.io/verification.html

Les données du document s'affichent pour comparaison avec le document papier.

9. Mode réseau (Pack Réseau Pro)

  1. PC Serveur : Paramètres → Réseau → ☑️ Activer serveur → Démarrer
  2. PC Client : Paramètres → Réseau → entrer l'IP du serveur → Se connecter

Les données sont synchronisées en temps réel entre tous les PC connectés.

10. Sauvegardes

Menu → Sauvegarde → Exportez la base de données sur une clé USB. Il est recommandé de sauvegarder chaque semaine.

11. Raccourcis et astuces

  • Échap : ferme la fenêtre active
  • Clic dans le vide : ferme les popups
  • Double-clic sur une ligne : modifie l'élément
  • Ctrl+C/V : copier/coller dans les champs texte
