Sécurité
Pourquoi les bulletins scolaires doivent être vérifiables
La falsification des bulletins est un problème réel au Burkina Faso. Découvrez comment le QR code anti-fraude protège l'intégrité des résultats.
27 Août 2026 • 5 min de lecture

Chaque année, des centaines de bulletins falsifiés circulent au Burkina Faso. Des parents ou des élèves modifient les notes pour cacher un échec ou obtenir une admission injustifiée.

Avec le QR code certifié de Yiriba, chaque bulletin contient une signature numérique unique. N'importe qui peut scanner ce QR avec son téléphone pour vérifier instantanément l'authenticité du document sur notre site officiel.

Si une seule lettre est modifiée sur le PDF, la vérification échoue. C'est la même technologie utilisée par les banques et les administrations publiques.

Gestion
5 erreurs fréquentes dans la gestion financière des écoles
Les écoles perdent souvent de l'argent à cause d'un suivi des paiements mal géré. Voici les erreurs à éviter absolument.
20 Août 2026 • 4 min de lecture

1. Pas de reçu — Sans reçu, le parent peut nier avoir payé. Yiriba génère automatiquement des reçus PDF avec QR code.

2. Pas de suivi des impayés — Le tableau de bord affiche en temps réel les élèves en retard de paiement.

3. Pas de backup — Une panne = données perdues. Les sauvegardes automatiques de Yiriba protègent vos données.

4. Pas de séparation des rôles — Le comptable ne devrait pas pouvoir modifier les notes. Le système de rôles gère ça.

5. Pas de rapports — Sans statistiques, impossible de prendre de bonnes décisions.

Réseau
Mode réseau : connecter plusieurs PC dans votre école
Comment mettre en place le mode réseau pour que le directeur, le comptable et le secrétaire travaillent simultanément.
10 Août 2026 • 6 min de lecture

Le mode réseau de Yiriba permet de connecter jusqu'à 5 PC sur le même réseau local. Un PC est le serveur, les autres sont des clients.

Pour activer le mode réseau :

1. Choisissez le PC le plus puissant comme serveur
2. Activez "Mode Réseau" dans Paramètres
3. Notez l'IP affichée (ex: 192.168.1.100:8765)
4. Sur les autres PC, entrez cette adresse IP
5. Connectez-vous avec vos identifiants

Les données sont synchronisées automatiquement. Si le serveur est éteint, les clients travaillent en mode local et se resynchronisent quand le serveur revient.
