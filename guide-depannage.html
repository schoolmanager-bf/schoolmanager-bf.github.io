1. Problèmes d'installation

❌ "Windows protège votre PC" — SmartScreen bloque l'installation

Windows affiche un avertissement car l'application n'est pas signée numériquement.

✅ Solution
1Cliquez sur "Informations complémentaires"
2Cliquez sur "Exécuter quand même"
3L'installation se lance normalement
❌ L'installation échoue avec une erreur d'accès
✅ Solution
1Fermez tous les processus Yiriba (Gestionnaire des tâches → fin de tâche)
2Clic droit sur le setup → "Exécuter en tant qu'administrateur"
3Si ça ne marche pas, désinstallez l'ancienne version d'abord
❌ ".NET Desktop Runtime requis"

L'installateur self-contained devrait inclure le runtime. Si ce message apparaît :

✅ Solution
1Téléchargez le setup self-contained (pas le框架-dependent)
2Ou installez .NET 10 Desktop Runtime depuis https://dotnet.microsoft.com/download

2. Problèmes au lancement

❌ L'app ne démarre pas / crash silencieux
✅ Solutions
1Vérifiez les logs : ouvrez %LOCALAPPDATA%\Yiriba\Logs\ et lisez le fichier le plus récent
2Corrompu : supprimez le dossier %LOCALAPPDATA%\Yiriba\ et relancez
3Antivirus : ajoutez une exception pour C:\Program Files\Yiriba\Yiriba.exe
4Réinstallez : désinstallez puis réinstallez avec le setup self-contained
❌ "Le processus ne peut pas accéder au fichier car elle est utilisée par un autre processus"
✅ Solution
1Ouvrez le Gestionnaire des tâches (Ctrl+Shift+Esc)
2Cherchez tous les processus Yiriba.exe
3Clic droit → "Terminer l'arborescence du processus"
4Relancez Yiriba
❌ L'app s'ouvre mais l'écran est noir
✅ Solution
1La base de données est peut-être corrompue
2Sauvegardez %LOCALAPPDATA%\Yiriba\schoolmanager.db
3Supprimez le fichier et relancez — une nouvelle base sera créée
4Importez la sauvegarde depuis Paramètres → Sauvegarde

3. Problèmes de connexion

❌ "Identifiants incorrects"
✅ Solutions
1Admin par défaut : login = admin, mot de passe = admin123
2Changement obligatoire : au 1er login, vous devez changer le mot de passe
3Mot de passe oublié : un admin peut réinitialiser depuis Paramètres → Utilisateurs
4Dernier recours : supprimez %LOCALAPPDATA%\Yiriba\schoolmanager.db (perte de données)
❌ "Compte désactivé"
✅ Solution
1Connectez-vous avec un compte Admin
2Allez dans Paramètres → Utilisateurs
3Cliquez ✏️ sur l'utilisateur → cochez "Actif" → Enregistrer

4. Problèmes de notes et bulletins

❌ Les notes ne sauvegardent pas
✅ Solutions
1Vérifiez qu'une année scolaire active existe (Paramètres → Années)
2Vérifiez que l'élève est inscrit dans une classe pour cette année
3Les notes doivent être entre 0 et 20
4Pour les décimales, utilisez virgule (ex: 14,5) ou point (ex: 14.5)
❌ Le rang est toujours le même pour tous les élèves
✅ Solution
1Vérifiez que les notes sont bien enregistrées pour TOUS les élèves
2Le rang est calculé sur la moyenne générale de la classe
3Si un seul élève a des notes, il est automatiquement rang 1
❌ La note de conduite ne s'affiche pas sur le bulletin
✅ Solution
1Allez dans Paramètres → Notes & Conduite
2Choisissez le mode de sanction : "Retrait sur la conduite"
3Configurez les retraits (absence, retard, incivisme)
4La conduite commence à 20/20 et diminue selon les retraits
❌ Le bulletin ne s'affiche pas en PDF
✅ Solutions
1Vérifiez que l'élève a au moins une note pour la période sélectionnée
2Vérifiez que la classe a des matières configurées
3Le fichier PDF est sauvé dans le dossier choisi

5. Problèmes de paiements

❌ "Le montant doit être supérieur à 0"
✅ Solution
1Entrez un montant positif (ex: 25000)
2Pour les décimales, utilisez la virgule (ex: 25000,50)
❌ Le solde ne se met pas à jour après un paiement
✅ Solution
1Cliquez sur "Actualiser" dans le tableau de bord
2Vérifiez que l'élève est bien inscrit dans une classe avec des frais définis

6. Problèmes réseau (multi-PC)

❌ "Serveur inaccessible" côté client
✅ Vérifications
1Les 2 PC sont-ils sur le même réseau WiFi/ethernet ?
2Le pare-feu bloque-t-il le port 8765 ? → Autorisez Yiriba dans le pare-feu
3L'IP saisie est-elle correcte ? → Vérifiez sur le PC serveur dans Paramètres
4Le serveur est-il bien démarré ? → Vérifiez l'indicateur "Serveur 192.168.x.x:8765" dans la sidebar
5Testez avec le mode démo (Réseau → bas de page) pour isoler le problème
❌ Autoriser le pare-feu Windows
✅ Solution
1Ouvrez Pare-feu Windows Defender → Autorisations
2Cliquez "Autoriser une application"
3Ajoutez Yiriba.exe pour les réseaux Privé et Public
4Ou ouvrez le port 8765 en TCP entrant
❌ Les données ne se synchronisent pas entre les PC
✅ Solutions
1Vérifiez que le PC client est bien connecté (indicateur vert dans la sidebar)
2Seul le PC serveur peut modifier les données
3Le client est en mode lecture seule (sauf pour les notes)

7. Problèmes de mise à jour

❌ "Impossible de vérifier les mises à jour"
✅ Solutions
1Vérifiez votre connexion internet
2Vérifiez que le site schoolmanager-bf.github.io est accessible dans votre navigateur
3Désactivez temporairement l'antivirus ou le proxy
4Téléchargez manuellement depuis https://schoolmanager-bf.github.io
❌ La mise à jour télécharge mais ne s'installe pas
✅ Solution
1Fermez Yiriba complètement
2Exécutez le setup téléchargé manuellement depuis %TEMP%\Yiriba_Update\
3Ou téléchargez depuis le site web

8. Problèmes de données

⚠️ AVANT toute manipulation, faites une SAUVEGARDE !

Paramètres → Sauvegarde → Sauvegarder et quitter

❌ La base de données est corrompue
✅ Solution
1Fermez Yiriba
2Allez dans %LOCALAPPDATA%\Yiriba\
3Renamez schoolmanager.db en schoolmanager.db.old
4Relancez Yiriba — une nouvelle base sera créée
5Importez la sauvegarde la plus récente
❌ Récupérer les données après désinstallation
✅ Solution

Les données sont dans %LOCALAPPDATA%\Yiriba\, PAS dans le dossier d'installation. La désinstallation ne supprime PAS les données.

1Relancez Yiriba — vos données sont toujours là
2Si perdues, cherchez un fichier schoolmanager_backup_*.db
❌ Faire une sauvegarde complète
✅ Solution
1Copiez %LOCALAPPDATA%\Yiriba\schoolmanager.db sur une clé USB
2Ou utilisez Paramètres → Sauvegarde → Sauvegarder sur USB
3Faites une sauvegarde chaque semaine

9. Problèmes PDF et signatures

❌ Le PDF ne s'ouvre pas
✅ Solutions
1Installez un lecteur PDF : Adobe Reader ou Sumatra PDF (gratuit)
2Vérifiez l'espace disque disponible
3Essayez un autre dossier de destination
❌ La signature électronique ne fonctionne pas
✅ Solutions
1Vérifiez que la clé QR est configurée (Paramètres → Sécurité)
2Pour vérifier : scannez le QR code avec n'importe quel lecteur
3Ou ouvrez https://schoolmanager-bf.github.io/verification.html?id=XXXXX

10. Problèmes de performance

❌ L'app est lente
✅ Solutions
1Nettoyez les logs : supprimez les anciens fichiers dans %LOCALAPPDATA%\Yiriba\Logs\
2Réduisez la base : supprimez les anciennes années scolaires (Paramètres)
3Redémarrez l'application
4Installez sur SSD si possible (beaucoup plus rapide)

11. Réinitialisation et réparation

⚠️ RÉINITIALISATION COMPLÈTE — Toutes les données seront perdues !

Faites une sauvegarde AVANT si vous voulez garder vos données.

✅ Étapes de réinitialisation complète
1Fermez Yiriba
2Supprimez %LOCALAPPDATA%\Yiriba\ (tout le dossier)
3Désinstallez Yiriba (Paramètres Windows → Applications)
4Redémarrez le PC
5Réinstallez avec le dernier setup
6Connectez-vous avec admin / admin123

12. Consulter les logs

ℹ️ Les logs sont dans : %LOCALAPPDATA%\Yiriba\Logs\
✅ Comment accéder aux logs
1Ouvrez l'Explorateur de fichiers
2Dans la barre d'adresse, tapez : %LOCALAPPDATA%\Yiriba\Logs\
3Ouvrez le fichier yiriba_YYYYMMDD.log avec le Bloc-notes
4Cherchez les lignes contenant "ERROR" ou "WARN"
✅ Envoyer les logs au support
1Copiez le contenu du fichier .log
2Envoyez-le par email à dieudonnetassembedo07@gmail.com
