🔑 Licence — HMAC-SHA256

AlgorithmeSHA-256
Format cléTYPE-XXXX-XXXX-XXXX-HASH4
Input hash{type}-{body}-{machineId}-{SECRET}
Extraction4 premiers caractères hex du hash
Lien machineWMI Win32_BaseBoard + Win32_BIOS
Types1MO, 1AN, 2AN, 5AN

📄 Génération de documents

Bulletins PDF (QuestPDF)

• Génération fluide via API Document.Create()

• Layout : Header école → Infos élève → Tableau notes → Moyennes → Mentions → Footer QR

• QR code intégré (QRCoder → Base64 PNG)

• Signature numérique (HMAC empreinte)

• 2 modèles : Standard / Lycée

Reçus de paiement

• Format sur une seule page A4

• Infos école + élève + montant + date

• QR de vérification intégré

• Empreinte anti-fraude HMAC

• Impression directe ou export PDF

☁️ Backend Cloudflare Workers

Worker Admin Dashboard

• worker-full.js — ~700 lignes JS

• Auth : SHA-256 password + HMAC session cookie

• CSRF protection (token par formulaire)

• Rate limiting : 5 tentatives / 15 min (via KV)

• Session 60 min auto-expiry

• Pages internes : Dashboard + Générateur licences

API Endpoints

• POST /auth → Login avec CSRF + rate limit

• GET /admin.html → Dashboard protégé

• GET /generator/ → Générateur licences

• POST /generate-license → API clé licence

• GET /logout → Destruction session

• GET /* → Proxy GitHub Pages (site public)
