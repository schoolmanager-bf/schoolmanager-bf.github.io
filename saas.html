FAQ

Questions fréquentes

C'est vraiment gratuit ?+
Oui, le plan Démo est 100% gratuit et sans limite de temps. Il permet de gérer jusqu'à 50 élèves.
Mes données sont-elles sécurisées ?+
Toutes les données sont chiffrées et hébergées sur des serveurs sécurisés.
Puis-je importer depuis Excel ?+
Oui ! L'import CSV/Excel est supporté pour les élèves, notes et paiements.
Faut-il une connexion internet ?+
Oui, c'est une application web. Mais l'interface fonctionne même avec une connexion lente (2G/3G).
Les bulletins PDF sont-ils officiels ?+
Oui. Les bulletins incluent le logo, le directeur, les signatures et un QR code de vérification.
